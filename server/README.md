# Habit Tracker

Full-stack habit tracking application built with React, TypeScript, Node.js, Express and PostgreSQL.

## Features

- User registration and login
- JWT authentication
- Create, edit and delete habits
- Habit scheduling
- Mark habits as completed
- Undo completions
- Habit statistics
- Current streak
- Best streak
- Success percentage
- Monthly habit calendar
- Completion history
- Dashboard navigation
- Responsive design

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express
- TypeScript
- PostgreSQL
- JWT
- bcrypt
